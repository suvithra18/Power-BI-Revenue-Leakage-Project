Project Name:
Revenue Leakage & SLA Risk Analytics Dashboard

Description:
Power BI dashboard designed to analyze revenue leakage caused by delayed invoices and SLA breaches.
The solution provides insights into delay patterns, SLA penalties, risk levels, and financial impact, enabling proactive monitoring and data-driven decision-making to reduce revenue loss.

Tools Used:
Power BI, Power Query, DAX,Mysql,Python
